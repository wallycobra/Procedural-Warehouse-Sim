# Randomly Generated Warehouse Simulation

A randomly generated warehouse simulation built in Unity and C# featuring autonomous robot missions, dynamic warehouse layouts, and backend integration with ASP.NET Core and PostgreSQL.
<img width="1206" height="863" alt="miniWarehouse" src="https://github.com/user-attachments/assets/eef3b198-6917-4d11-b358-26da5ffe19a0" />

## Features

* Procedural NxM warehouse generation
* Maze-style traversable path system
* Dynamic rack, pickup, parking, and dropoff generation
* Autonomous robot mission system
* A* pathfinding for robot navigation
* Runtime warehouse regeneration
* Animated warehouse generation/destruction effects
* Simulation speed controls
* Audio and visual polish systems


## Mission Flow

```text
Parking
→ Pickup
→ Dropoff
→ Return to Parking
→ Repeat
```
